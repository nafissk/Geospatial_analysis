# Geospatial_analysis

Geospatial analysis notebooks for raster data and building footprints.

## Notebooks

- [`01_raster_read_visulaize.ipynb`](notebook/01_raster_read_visulaize.ipynb) — Demonstrates how to use GDAL and Rasterio to read and visualize raster data.
- [`02_Building_footprint_Microsoft.ipynb`](notebook/02_Building_footprint_Microsoft.ipynb) — Select Microsoft building-footprint tiles for a study-area bounding box, clip the buildings, and export the footprints and a 30 m raster.
- [`02_Building_footprint_Global_ATLAS.ipynb`](notebook/02_Building_footprint_Global_ATLAS.ipynb) — Download and clip Global Building Atlas footprints for a study-area bounding box, then export the footprints and a 30 m raster.
